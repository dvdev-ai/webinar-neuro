# Вебинар по нейросетям

Рабочая папка по инициативе образовательных вебинаров.

## Файлы

- `Справка_цели_ветки_вебинара_v1.0.docx` - цели эфира, ветки ЦА, референсы, анонс (Word)
- `Справка_поминутный_план_вебинара_90_мин_v1.0.docx` - полная программа на 90 минут (Word)
- `Цели_ветки_и_референсы.md` - исходник целей и веток
- `Поминутный_план_90_минут.md` - краткая версия программы
- `Структура_и_сценарии_вебинара.md` - структура эфира, сценарии, воронка, KPI
- `gen_spravka_celi_vetki.py` - генератор справки по целям
- `gen_spravka_plan_90.py` - генератор поминутного плана
- Референс: `../Справка_вебинары_нейросети_v1.0.docx`

## Цель

Отработать программу вебинара так, чтобы его можно было провести и масштабировать: PR, лиды, найм, пилоты услуг.
